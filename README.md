# 🔐 Login Page

## 📌 About

This project is a simple and responsive login page built using HTML and CSS. It provides a basic user authentication interface with email and password input fields along with a forgot password option. The design focuses on simplicity and usability.

## 🛠️ Technologies Used

* HTML5
* CSS3
* Font Awesome (for icons)

## ✨ Features

* Email and password input fields
* Forgot password link
* Clean and minimal UI
* Beginner-friendly frontend project

## 📂 Project Structure

```
login-page/
│── index.html
│── ex.css
│── forgot.html
│── man.png
│── README.md
```

## 🚀 How to Run

1. Download or clone the repository
2. Open `index.html` in any web browser
3. Use the login interface

## 🎯 Purpose

This project is created for learning frontend web development and understanding the structure of a login page UI.
